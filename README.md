### ⭐ Featured projects

**[The Lenny Growth Assistant](https://github.com/beutkarshh/The-Lenny-Growth-Assistant)** — grounded, cited Q&A over 53 episodes of Lenny's Podcast.
RAG on PostgreSQL + pgvector with deep links to the exact moment in the source video; a tool-calling agent with **two swappable providers** (Claude in the cloud, Ollama fully local) behind one interface; designed spec-first with a PRD and architecture docs before any code.
`FastAPI` · `React` · `pgvector` · `Claude API` · `Ollama` · `Docker`

**[AI Web Nav](https://github.com/beutkarshh/AI_WEB_NAV)** — 🥈 *1st Runner-Up, ByteXL HackXLerate*
LLM shopping agent: a plain-English request is parsed into structured intent by a local LLM, which also picks the right stores; Playwright then browses Amazon, Flipkart and Myntra and returns one normalised, budget-filtered ranking. Round 2: a resumable Wikipedia crawler with job tracking.
`Python` · `Playwright` · `Ollama` · `FastAPI` · `SQLite`

**[PRISM — Multi-Agent Medical Reasoning](https://github.com/beutkarshh/GDHS-Hackathon)** — 🥉 *2nd Runner-Up, Global Digital Health Summit Hackathon*
Five LangGraph agents in sequence — symptom analysis → PubMed literature → ontology case-matching → RxNorm treatments → summary — producing a downloadable clinical PDF report, with deterministic fallbacks when no LLM key is set.
`LangGraph` · `FastAPI` · `React` · `TypeScript`

**[AI SQL Assistant](https://github.com/beutkarshh/AI-Powered-SQL-Query-Generator)** — plain English → SQL grounded in your live schema, running on a local model.
I rebuilt a team project around local Ollama inference and added schema-grounded generation, a provider abstraction, read-only mode, and a DDL → Prisma / Mermaid ER converter.
`Node.js` · `MySQL` · `Ollama` · `React`
